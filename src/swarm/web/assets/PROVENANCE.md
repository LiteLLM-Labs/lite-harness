# Visual assets

The Canvas constellation in `constellation.js` directly ports the deterministic golden-angle star positions, drift, local-worker processing, glints and curved packet formulas from the approved Lens `AgentSwarmField.tsx` and `DeepSpaceBackdrop.tsx`. The original reference is the user's `lens-space-launch` skill. Its space, palette and typography are preserved; the layout is adapted into an interactive product. Particles are decoration, never agent counts. Solid paths connect actual agent cards to their shared coordination context; animated traffic indicates activity, not individual network requests. Archived runs can also display their original declared dependencies as dashed paths.

The Swarm mark is an original generic coordination glyph. It does not represent LiteLLM or another harness.

Local Geist and Geist Mono variable fonts are copied from the approved Lens template. Codex and Claude Code marks are unmodified copies from the existing Swarm Studio assets, originally sourced from https://github.com/BerriAI/moyai/tree/d4ff45e0ae3e4bd1c8380587ca99b3adf89a1cba/app/static/harness-logos. OpenCode's unmodified mark comes from https://raw.githubusercontent.com/anomalyco/opencode/dev/packages/ui/src/assets/favicon/favicon-v3.svg, previously downloaded on 2026-10-10. Marks identify harness selection and do not imply endorsement.

Model-provider identity marks `model-openai.svg` and `model-anthropic.svg` are unmodified copies from the existing local LiteLLM dashboard assets (BerriAI/litellm `ui/litellm-dashboard/public/assets/logos/openai_small.svg` and `anthropic.svg`). The Pi harness mark is copied unchanged from the earlier Swarm Studio package, sourced from the Moyai harness-logo set linked above. In the live feed the larger icon identifies the harness and the smaller model icon identifies the recognized model provider; unknown model families receive the generic Swarm mark.
