Start with one managed coding agent for the analytics team.

The v0 does not try to model the whole enterprise. It gets a team from “we built a helpful CI-fixing assistant” to “any repo owner can launch it safely through UI or API.”

Pick the agent job CI fixer first, then Power BI and customer-facing agents later.
